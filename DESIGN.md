# Shared Router interface

Owner operations dashboard, optimized for reading small amounts of real account data and making explicit access changes.

The approved workflows determine the surface: a token ledger first, named people and keys second, and connection/model review third. Warm paper, quiet green navigation, thin ruled tables, and restrained controls keep the focus on readable accounting. Use native system typography for this utilitarian interface. No fabricated metrics, gradients, illustrations, or decorative charts.

Primary ink #262c27, secondary #596359, action #345c41, paper #faf9f6. Tables use tabular numerals and right-aligned numbers. Unknown counts use an em dash and explicit incomplete status. Mobile navigation becomes a horizontal row; dense ledgers scroll inside their own container.

One-time keys appear in a focused dialog and are erased from the DOM when it closes. Every form has visible labels and recoverable error feedback. Honor reduced-motion preferences. Product truth comes from PRODUCT.md and the user-approved implementation plan.
